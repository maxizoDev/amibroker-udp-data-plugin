Build, Package, and Ship!

  1. Build: - Open Examples/DataPlugEX in Visual Studio (64-bit Release) - Confirm all source and new files added to project - Add spdlog and any external files as "Include" directories - Make sure plugin exports pass (dumpbin /exports yourplugin.dll)
  2. Test: - Place DLL in AmiBroker’s Plugins folder - Start AmiBroker, use Tools > Plugins to load - Configure UDP/IP/dealer, check for socket bind & log - Start data feed and verify chart updates
  3. Package: - Collect DLL, config templates, and README into a ZIP, publish or upload as needed
