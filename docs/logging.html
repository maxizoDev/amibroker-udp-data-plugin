Feature: Logging (Critical Events Only)

Integrate spdlog or similar for per-day log file, only log startup, config, error events.

New file or append to logging.h/cpp 

#include <spdlog/spdlog.h>
#include <spdlog/sinks/daily_file_sink.h>
inline std::shared_ptr<spdlog::logger> get_logger() {
    static auto logger = spdlog::daily_logger_mt("plug", "plugin_log.txt");
    return logger;
}
Patches
  • On UDP bind failure:
    get_logger()->error("UDP bind error: {}", WSAGetLastError());
  • On configuration update:
    get_logger()->info("Config updated: {} {}", pluginConfig.udpBindIp, pluginConfig.dealerId);
