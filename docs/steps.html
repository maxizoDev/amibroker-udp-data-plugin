Workflow: Adapting DataPlugEX for UDP Real-Time Feeds

  1. Clone the ADK and copy Examples/DataPlugEX/ as your plugin base.
  2. Edit dataplugex.cpp and related files as documented in feature sections.
  3. Implement/patch:
    • Settings UI & Dealer ID
    • UDP engine (background thread) & packet decode
    • Thread-safe tick buffer
    • Critical event logging
    • Placeholders for backfill
  4. Compile as 64-bit release DLL.
  5. Test in AmiBroker (plugin config dialog, live feed, backfill placeholder).
  6. Package and ship (DLL, any license/readme/docs, release artifact ZIP).
